# Sukesh Varma — Premium Next.js Portfolio

Live site: `https://sukesh-varma-portfolio.vercel.app`

## Run locally
```bash
npm install
npm run dev
```

## Deploy free on Vercel
1. Push this folder to GitHub.
2. Go to Vercel → Add New Project → Import GitHub repo.
3. Framework auto-detected: Next.js.
4. Click Deploy.

## Dynamic projects
Projects are stored in `data/projects.ts` and exposed via `/api/projects`.
